## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-30 | Tampering | Preview build migrating main | mitigate | Preview vars set to dev by hand, preview branching off; build log host checked in Task 3 |
| T-02-31 | Information disclosure | secrets in logs/files | mitigate | Values piped on stdin, never echoed; .env.production.local deleted; `.env*` gitignored |
| T-02-32 | Tampering | concurrent CI + Vercel migrations on dev | mitigate | pg_advisory_lock in scripts/migrate.ts |
| T-02-33 | Elevation | XSS / clickjacking | mitigate | Report-Only CSP now (enforce in a later phase after reviewing reports), frame-ancestors 'none', X-Frame-Options DENY, nosniff |
| T-02-34 | Information disclosure | admin indexing | mitigate | X-Robots-Tag on /admin/:path* plus robots metadata |
| T-02-35 | Tampering | overwriting main data | mitigate | Seed on main once, without --force; stop and ask if non-empty |
| T-02-36 | Spoofing | shared BETTER_AUTH_SECRET | mitigate | Distinct random secrets for local, CI, Preview and Production |
</threat_model>
