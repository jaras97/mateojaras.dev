| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-19 | Elevation of privilege | GET /api/draft | mitigate | requireSessionForRequest first; e2e asserts 401 without cookie |
| T-03-20 | Spoofing (open redirect) | GET/POST /api/draft | mitigate | GET builds the path from the DB row with getPathname; POST uses safeReturnPath (tests for //, scheme and backslash forms) |
| T-03-21 | Information disclosure | Draft content in public pages | mitigate | cookie httpOnly/secure/SameSite None set by Next; drafts only through applyDraft when isEnabled; cookieless e2e assertion |
| T-03-22 | Tampering (CSRF) | POST /api/draft disable | accept | Disabling preview has no impact beyond Teo's own session view |
</threat_model>
