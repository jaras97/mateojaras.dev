## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/auth/* | credentials and session cookies from the internet |
| browser → /admin/* and Server Actions | requests may skip proxy.ts or forge cookies |
| other Vercel deployments → our origin | cross-origin requests (CSRF surface) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-19 | Spoofing | login brute force | mitigate | Login only via Better Auth HTTP router (special rule 3 req / 10 s on /sign-in); storage per 02-01 B; Upstash in phase 4 |
| T-02-20 | Elevation | proxy bypass / forged cookie | mitigate | AuthGate + requireSession on every loader and action; e2e (c) |
| T-02-21 | Spoofing | revoked session replay | mitigate | DB sessions, cookieCache off, signOut revokes; e2e (b) |
| T-02-22 | Tampering | CSRF via trusted origins | mitigate | allowedHosts from VERCEL_* + localhost (off Vercel) only; no wildcard; acceptance grep |
| T-02-23 | Elevation | second account creation | mitigate | disableSignUp true; e2e (d); seed creates only ADMIN_EMAIL |
| T-02-24 | Information disclosure | account enumeration | mitigate | One generic login error message |
| T-02-25 | Information disclosure | admin indexing | mitigate | robots noindex in admin layout (X-Robots-Tag header added in 02-07) |
| T-02-26 | Information disclosure | BETTER_AUTH_SECRET | mitigate | Only in .env.local / Vercel / GitHub secrets; Better Auth refuses the default secret in production |
</threat_model>
