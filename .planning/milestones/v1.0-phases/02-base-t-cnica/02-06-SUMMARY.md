## Deviations from Plan

**1. [Rule 3 - Blocking] schema contract test counted the new auth tables.** `src/db/schema.test.ts` compared every exported table with docs/data-model.md; it now excludes user/session/account/verification (generated by the auth CLI, outside the doc). Included in b98476c.

**2. [Rule 1 - Bug] createUser type needs a second argument.** 1.7.25 types require a `source`; it is only read when `user.validateUserInfo` is configured (it is not), so a placeholder is passed with a comment. Isolated in scripts/lib/admin.ts.

**3. Session cookie is `__Secure-better-auth.session_token`.** With `protocol: 'auto'` Better Auth marks the cookie Secure and prefixed even on localhost:3100; Playwright's request jar and Chrome accept it on localhost. The e2e matches the optional prefix. 02-07 should confirm the browser flow behaves the same.

**4. Memoization test is a source check.** React `cache()` only dedupes inside a render, so the "one getSession call per render" behavior is not unit-testable under Vitest; the test asserts the `cache(` wrapper textually. Weak by necessity; real coverage comes from 02-07 e2e.
