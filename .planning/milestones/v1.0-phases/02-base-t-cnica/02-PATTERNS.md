# Phase 2: Base técnica - Pattern Map

**Mapped:** 2026-11-15
**Files analyzed:** 52 new/modified/deleted
**Analogs found:** 27 / 52. The rest are greenfield infrastructure: DB, auth, proxy, i18n, CI, e2e. For those, use the RESEARCH.md patterns cited in each row.

The codebase is a phase 1 scaffold. Here is what it has and lacks:
- **Has:** the project conventions (comment style, Zod contract, fs readers, the server spawn harness, Vitest style, messages parity, the font module, the Button).
- **Lacks:** anything Drizzle, Better Auth, next-intl, `'use cache'`, Server Actions, Route Handlers, `proxy.ts`, Playwright config or GitHub workflows.

The "analog" for that second group is the convention to copy, not a working example. Only git-tracked paths are referenced.

## Pattern Assignments

### `src/app/[locale]/layout.tsx` and `src/app/admin/layout.tsx` (root layouts)

**Analog:** `src/app/layout.tsx` (deleted in this phase; copy it first).

Lines 1-15, the full file:
```tsx
import type { Metadata } from "next";
import { fontVariables } from "./fonts";
import "./globals.css";

export const metadata: Metadata = {
  title: "Mateo Jaramillo",
};

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html lang="en" className={`${fontVariables} h-full antialiased`}>
      <body className="min-h-full flex flex-col">{children}</body>
    </html>
  );
}
```

Adaptations:
- **Imports:** `fonts.ts` and `globals.css` live in `src/app/`, so import them as `"../fonts"` and `"../globals.css"` (or `@/app/fonts`). Keep `fontVariables` from `src/app/fonts.ts` line 26 in **both** root layouts (the comment on fonts.ts line 6 anticipates this).
- **Typing:** use the global `LayoutProps<"/[locale]">` / `LayoutProps<"/admin">` helpers (generated by `next typegen`, already used here and in `lab/layout.tsx` line 10).
- **`[locale]` layout:** `lang` comes from `await locale()` (`next/root-params`) after a `hasLocale` check, then `notFound()`. Add `generateStaticParams` returning `[{locale:'en'},{locale:'es'}]`. Wrap children in `NextIntlClientProvider` only if a client component needs messages (none does in phase 2 except the admin login).
- **Admin layout:** use `lang="es"` and the robots metadata from `src/app/lab/layout.tsx` lines 6-8:
```tsx
export const metadata: Metadata = {
  robots: { index: false, follow: false },
};
```
- **Shell classes:** `min-h-dvh bg-background text-foreground` from `lab/layout.tsx` line 16. Use the tokens only; no zinc classes from the scaffold `page.tsx`.

function asRecord(value: unknown): Record<string, unknown> {
  return typeof value === "object" && value !== null && !Array.isArray(value)

function pendingOf(frontMatter: unknown): string[] {
