| browser/internet → /api/auth/* | credentials and session cookies from the internet |
| other Vercel deployments → our origin | cross-origin requests (CSRF surface) |
| seed script → user/account tables | admin credentials from .env.local |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-19 | Spoofing | login brute force | mitigate | Login only via Better Auth HTTP router (special rule 3 req / 10 s on /sign-in); storage per 02-01 B; Upstash in phase 4 |
| T-02-21 | Spoofing | revoked session replay | mitigate | DB sessions, cookieCache off (acceptance grep), signOut revokes; e2e/auth-api.spec.ts case (c); UI-level replay in 02-07 |
| T-02-22 | Tampering | CSRF via trusted origins | mitigate | allowedHosts from VERCEL_* + localhost (off Vercel) only; no wildcard; acceptance grep |
| T-02-23 | Elevation | second account creation | mitigate | disableSignUp true; e2e case (b); seed creates or re-hashes only ADMIN_EMAIL; user count acceptance |
| T-02-26 | Information disclosure | BETTER_AUTH_SECRET | mitigate | Only in .env.local / Vercel / GitHub secrets; Better Auth refuses the default secret in production |
</threat_model>
